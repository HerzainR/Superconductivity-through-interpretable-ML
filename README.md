# Describing-superconductivity-through-interpretable-AI

## Description
This repository contains the data analysis and visualization for the modeling of the critical temperature of conventional superconductors using the SISSO (Sure Independence Screening and Sparsifying Operator) artificial intelligence approach. It is intended to support the reproducibility of the results presented in the associated study.

## Repository structure 
The repository contains different folders with particular pieces of information. These are the following

1. Dataset: The data.csv file in this folder is the data used as input for all the SISSO studies.

2. SISSO_raw_data: This folder has all the SISSO runs used for our Cross-Validation studies, and used for the tuning of the hyperparameters rung and model dimensionality (1-5).  

3. Data_analysis: Here, the Jupiter Notebook superconductivity_SISSO.ipynb aims for the reproducibility of the main results presented in the manuscript.
